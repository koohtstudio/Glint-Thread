# Decisions log

One line each: decision, then reason.

- Node 24 LTS installed via nvm and pinned in `.nvmrc`; Sanity 6 and Vitest 5 require Node >= 22.12 and the machine default was 20.19.
- TypeScript 6.0.3 instead of 7.0: typescript-eslint (used by eslint-config-next) supports TS < 6.1 only.
- ESLint 9 instead of 10: eslint-plugin-react (in eslint-config-next 16.4) peers on ESLint <= 9.
- Kept Next 16 Cache Components and Partial Prefetching (create-next-app defaults); data functions use `use cache` + `cacheTag`, and webhook revalidation uses `revalidateTag(tag, { expire: 0 })` per the bundled docs.
- Task list lives in `TASKS.md` because this session has no built-in todo tool; it is updated at each milestone.
- Detail lines containing "verify" (for example "Fibre content: see verify") are hidden on the storefront by `publicDetails()`; they are internal notes, and the facts live in `verify[]` for the Studio.
- Collection rules in products.json are prose; `parseCollectionRule()` turns them into structured rules (tags, max price, sort) so the JSON stays the source of truth.
- "Newest" uses catalogue position in local mode (later entries are newer) because the catalogue has no dates; Sanity mode uses `_createdAt`.
- Colour filter families come from variant names via a fixed vocabulary in `lib/data/derive.ts`; single-variant products fall back to their title ("Emerald Slouch Sling") so the filter still finds them.
- Final sale is derived from category (earrings, hair ties, beauty tools) or a `final-sale` tag, overridable by a product `finalSale` flag in Sanity (PRD 11.1 says "anything marked final sale").
- Children's warning shows for products tagged `kids` (PRD 12.8).
- Images narrower than 600 px are flagged `lowRes` and never rendered wider than their natural width.
- Blur placeholders are 10 px JPEG LQIPs generated by the image copy script into `lib/data/generated/image-meta.json` (committed, keyed by content hash) so tests and builds work without running the script first.
- Content page copy lives in `content/*.ts` as a small markdown dialect converted to Portable Text, so local mode and the Sanity seed share one source.
- Pricing engine marks the paying units of a buy-x-get-y group as promoted too, so overlapping promotions can never reuse them (PRD 9.1 rule 5).
- First-order-only codes (WELCOME10) need an email in the bag; checkout passes it to Stripe as customer_email so the checked email is the one used, and the webhook re-checks redemptions.
